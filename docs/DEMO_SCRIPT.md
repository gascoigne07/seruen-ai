# Демо Seruen AI: около трёх минут

Записывайте реальное приложение, открытое через `make run` на http://localhost:8501.
Для основной записи покажите настроенный серверный OpenAI и проверьте режим `openai`
на реальном ответе. Погоду оставьте выключенной. В публичном интерфейсе посетитель
сразу задаёт прогулку: вход и настройка модели ему не нужны. Резервный воспроизводимый
показ доступен через `SERUEN_PROVIDER=local` и перезапуск; его режим — `retrieval-template`.

Для демонстрации OpenAI владелец заранее настраивает серверный ключ, явный `OPENAI_MODEL`
и `SERUEN_PROVIDER=openai`, оставляет `SERUEN_DEMO=0` и перезапускает приложение.
Проверьте, что запрос завершился в режиме `openai`, а не дал локальный резервный ответ.
Реальный вызов `gpt-6-luna` проверен успешно, но перед записью всё равно проверьте текущий фактический режим. Не выдавайте
шаблоны за ответ внешней модели; сведения о проверке — в `docs/LIVE_VALIDATION.md`.

В отдельном коротком дубле проверьте фразу «я вот в центральном парке. куда могу отсюда
пойти»: старт должен быть Центральным парком, а не Байтереком. Для адреса с несколькими
совпадениями покажите выбор кандидата и подтверждение. Без указанного места программа
просит старт. Определение по тексту не является GPS; точка может обозначать центр объекта.

Перед записью очистите историю и проверьте подложку карты. Не открывайте `.env`,
терминал с ключами или личные вкладки. Настройку сервера выполните до записи.
Точные названия и числа проговаривайте по текущему экрану. Если подходящих мест нет,
сохраните этот результат.

Если переключение языка не пересчитывает ответ, отправьте запрос повторно:
`I have 45 minutes near Mega Silk Way and want a walk. Answer in English.`

После записи загрузите ролик на YouTube с доступом по ссылке и проверьте просмотр
в приватном окне браузера. Публикация требует вашего аккаунта и выполняется вручную.

Если запись проходит в локальном режиме, замените упоминание модели в начале на:

«Сейчас показываю резервный локальный режим. Поиск, ограничения и карточки работают
без вызова модели; тексты действий берутся из шаблонов. Реальное подключение OpenAI
проверено отдельно и описано в материалах проекта».

Если во время записи сработал `retrieval-template`, назовите этот режим. Не называйте
локальную карточку живым ответом модели. Для ролика можно сделать отдельный дубль
после восстановления подключения, сохраняя честное обозначение результата.
