# Приватность и источники

Seruen AI работает без аккаунтов посетителей. Владелец запускает сервер и настраивает
одно подключение модели. При локальном запуске сервер находится на компьютере владельца;
при размещении в интернете запросы и координаты обрабатывает выбранный владельцем сервер.
Приложение не записывает историю запросов или координаты на диск и не содержит собственной
аналитики. Последние пять ответов и запросов находятся в памяти отдельной сессии Streamlit.
Кнопка очистки удаляет эту историю, но сохраняет настройки и стартовую точку.
По желанию посетитель может скачать TXT-подборку: места, время и ссылки на источники,
без исходного запроса и точных координат старта. Скачанный файл остаётся у посетителя;
очистка истории его не удаляет. Места и расстояния всё равно могут раскрывать примерный
район прогулки. Кнопка скачивания не вызывает модель повторно.
«Обновить подборку» повторяет запрос с текущими условиями и может вызвать настроенную модель.

При подключённом OpenAI модель сначала выделяет текущий ориентир из текста запроса.
Название проверяется по локальным POI, проверенным ориентирам и при необходимости
внешнему Photon. Геокодер получает только короткое выделенное название или адрес:
не весь разговор, не предпочтения прогулки и не отдельное поле координат пользователя.
Неоднозначные варианты требуют выбора посетителя. Модель не задаёт координаты.
Сервис не запрашивает GPS браузера: результат — точка картографического источника
или центр объекта, а не точное положение человека или проверенный вход.

Photon-кэш хранится только в памяти процесса: до 512 поисковых фраз и их результатов,
не дольше 24 часов. Он общий для процесса и не содержит полного запроса или истории
разговора. Очистка истории сессии не очищает этот общий кэш; перезапуск процесса очищает.

## Где используются данные

| Получатель | Какие данные | Когда |
|---|---|---|
| Сервер Seruen AI и браузер посетителя | Точные координаты для расстояний и маркера, запрос, фильтры, ответ | Пока работает сессия |
| Панель «Какие данные использованы» | Координаты с тремя знаками после запятой | При показе ответа |
| OpenAI API | Текст запроса для выделения старта; при генерации контекст и до восьми карточек с расстояниями. Авторизация ключом владельца | При включённом OpenAI и соответствующем этапе конвейера |
| Google Gemini | Текст запроса, контекст и до восьми карточек с расстояниями | Если владелец выбрал и настроил дополнительный Gemini |
| Photon | До двух коротких названий/адресов в пределах Астаны, IP серверного соединения | Если локальный источник не подтвердил старт и внешний поиск разрешён |
| Open-Meteo | Координаты с двумя знаками, IP серверного соединения | Только при включённой погоде |
| CARTO и поставщики карты | Запросы подложки для области карты, IP браузера | При загрузке карты |
| Overpass, Wikidata, Wikipedia | Запросы по территории города и объектам POI | При ручном запуске сборщиков |

Округление до трёх знаков соответствует шагу примерно 111 м по широте и 70 м по долготе
на широте Астаны. Два знака дают шаг примерно 1,1 км и 0,7 км. Это уменьшение точности,
а не гарантия анонимности. Поставщики сервисов и инфраструктура размещения могут вести
собственные журналы; отсутствие записи истории в коде приложения не отменяет их политики.

Поле с точными координатами пользователя не передаётся внешней модели. Перед отправкой
текста фильтр заменяет десятичные числа, похожие на координаты. Это эвристика, а не
универсальная анонимизация: адреса, названия мест и нестандартная запись координат могут
остаться. Расстояния до известных объектов также позволяют приблизительно оценить положение.
Не включайте в запрос лишние персональные данные.

Погода выключена по умолчанию. Без серверного ключа действует локальный подбор;
владелец может явно выбрать `SERUEN_PROVIDER=local`. В нём модель не вызывается.
Предпочтения разбираются в Python, а определение старта в режиме OpenAI начинается с
вызова модели. Локальный режим не вызывает Photon. Внешний геопоиск отдельно отключается
через `SERUEN_GEOCODING=0`. Интернет также нужен для подложки карты. Для офлайн-демо используйте CLI с `--demo --no-weather`. При `make run`
сбор статистики Streamlit отключён параметром запуска.

## Подключение владельца

Ключ `OPENAI_API_KEY` хранится в серверном окружении или `.env`, исключённом из Git.
В интерфейсе нет полей ключей, входа, аккаунтов или выбора моделей. Посетитель
не предоставляет свои учётные данные. `.env` и ключи нельзя показывать в видеозаписи
или передавать вместе с проектом.

Генерация через OpenAI использует Responses API с `store: false` и `stream: false`.
`store: false` не является обещанием нулевого хранения у провайдера: политика мониторинга
злоупотреблений и другие применимые правила остаются в силе.
[Официальные правила обработки данных OpenAI API](https://developers.openai.com/api/docs/guides/your-data).

При ошибке выделения или проверки старта приложение использует доступные локальные
источники либо просит уточнение. Ошибка генерации после подтверждения старта приводит
к локальному ответу и общему пояснению. Сырые ошибки API посетителям не показываются.
Владелец может посмотреть классифицированную причину через CLI с `--json`.

## Что означает источник в ответе

- Источник старта может отличаться от источника рекомендаций: Photon возвращает OSM,
  а проверенный Центральный парк связан с [Visit Astana](https://visitastana.kz/ru/about-city/what-to-see/tsentralnyy-park/).
  Координаты описывают объект, а не фактическое положение пользователя.
- «Данные POI» относятся к информации из снимка OSM и, для некоторых описаний, Wikipedia.
  Ссылки на объекты и статьи позволяют сверить происхождение.
- «Идея сгенерирована» относится к предлагаемому действию. Она не подтверждает наличие
  услуг, оборудования или билетов.
- У 317 из 1 171 места заполнены часы работы. Непонятное расписание или отсутствие часов
  дают `unknown`. Это не равнозначно «открыто» или «закрыто».
- При явном требовании доступности проходят только объекты с `wheelchair=yes`.
  Такая отметка OSM не заменяет проверку маршрута и входа.
- Для 261 безымянной площадки проект создаёт название и сообщает об этом.
- Проверка идентификаторов исключает рекомендации вне найденного списка. Объяснения
  строятся локально по полям кандидата и контексту. Идея действия от модели проходит
  фильтр, исключающий типовые утверждения о часах, цене, удобствах и доступности,
  и сопровождается условием о возможности на месте. Это эвристика, а не доказательство
  фактической точности любой идеи. При отклонении действует локальный шаблон.

Инструкции внутри описаний и тегов считаются данными. Системный запрос требует их
игнорировать, а ответ дополнительно проходит проверку типов, идентификаторов и времени.
Это защита нескольких уровней, а не обещание абсолютной безопасности модели.

## Лицензии и преобразования

| Источник | Использование | Лицензия |
|---|---|---|
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | POI, координаты, теги, расписания; результаты Photon | ODbL 1.0, © OpenStreetMap contributors |
| [Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing) | Ссылки на статьи | CC0 |
| Wikipedia | 14 сокращённых описаний без разметки. Авторы Wikipedia, статья в `evidence` | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| [Open-Meteo](https://open-meteo.com/en/terms) | Погода при включении функции | Данные [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

Нормализация OSM меняет схему, переводит часть тегов, выводит описания из тегов и удаляет
близкие одноимённые записи. Wikipedia-текст очищен и может быть сокращён до 420 символов.
Сохраняйте атрибуцию и применимые лицензии при распространении данных. Хеш исходника
проверяет целостность файла, но не актуальность часов или точность сведений о заведении.

Google Maps и 2ГИС не служат источниками базы. Статические ссылки на такие сайты,
если пользователь открывает их сам, являются отдельным внешним переходом.
